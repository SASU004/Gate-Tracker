# GATE 2027 CS Syllabus Tracker

A small, local-first tracker for the GATE 2027 Computer Science & Information Technology syllabus. I built this for myself to keep lectures and PYQs organised without needing an account or an internet connection.

## Use it online

Open the live tracker at [sasu004.github.io/Gate-Tracker](https://sasu004.github.io/Gate-Tracker/).

## Run it locally

1. Download this repository, or download `index.html` on its own.
2. Double-click `index.html` to open it in a web browser.
3. Expand a syllabus section and tick off **Lectures** and **PYQs** as you finish them.

No installation, server, or sign-in is needed.

## Saving progress

Your progress is saved automatically in your browser's local storage. It stays available when you close and reopen the tracker in the same browser on the same device, including when using the live site.

Progress will not sync between browsers or devices, and clearing that browser's site data/local storage will remove it.
